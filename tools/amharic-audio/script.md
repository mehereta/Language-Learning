# Amharic recording script

244 lines in 13 takes of up to 20.

Record each take as one file named `take-01.m4a`, `take-02.m4a`, and so on. Read the lines in order and leave about 2 seconds of silence between them. For lines with “…”, pause briefly (under a second) where the blank is. If you make a mistake, stop and record the whole take again.
